# Pasco County Vacant Land Comps

Sale window: Apr 19 2026 through May 19 2026.

Filters applied from Pasco County PA weekly data dated May 17 2026: Sale_VacImp = V, Sale_Price > 500000, parcel Acres > 0.5. Grantor/current grantee context was enriched from Pasco PA parcel detail pages. Map coordinates are centroids from the public Pasco PA ArcGIS parcel layer.

Files:
- `pasco_vacant_land_comps_2026-04-19_to_2026-05-19.json` - JSON array using the ELC fields requested.
- `pasco_vacant_land_comps_2026-04-19_to_2026-05-19.csv` - readable summary table.
- `pasco_vacant_land_comps_2026-04-19_to_2026-05-19.html` - standalone Esri interactive map.
